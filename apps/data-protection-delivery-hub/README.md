# Data Protection Delivery Hub application

This folder contains the editable React/Vite application source.

**Run the published app:** https://amgarciajr.github.io/Data-Protection-Delivery-Hub/

The repository folder is the source package. The live link opens the interactive application; the root repository README opens when browsing the source on GitHub.

The app uses synthetic data and browser-local persistence. Dataverse, SharePoint, Entra security, audit, retention, ALM, monitoring, and support controls must be configured and tested before production use.
